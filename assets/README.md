# 示例与模型

本目录中的 NBS 示例为本项目生成，用于演示单音、多人声部和键位：

- `两只老虎.nbs`：传统童谣旋律的单人示例。
- `两只老虎_双人合奏.nbs`：同一传统旋律的双人编排示例。
- `小星星_三音轨示例.nbs`：传统旋律的三音轨示例。
- `半音组合试音.nbs`：为检查音区及半音组合生成的试音序列。

这些示例文件随项目采用 MIT 许可；本项目不对传统旋律本身主张原创权利。仓库不包含用户上传的歌曲或其转换成品。

`models/` 中的模型权重来自第三方作者，来源及许可见 [MODEL_CARD.md](models/MODEL_CARD.md)，不能视为本项目自行训练的模型。
